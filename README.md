# KUrowser

KUrowser는 고려대학교 학생의 LMS 할 일을 버튼 한두 번으로 끝내는 앱입니다.

첫 화면에 오늘 남은 마감, 안 본 강의, 새 공지, 새 자료가 나옵니다. 학생이 채팅창에 문장을 쓰면 앱이 알맞은 카드를 보여 주거나 학교 화면을 엽니다.

## 주요 기능

- 강의자료를 과목별 폴더에 받습니다.
- 녹화강의 자막과 요약을 만듭니다.
- 포털 공지, 학사 일정, 도서관 대출과 열람실, 성적과 시간표를 앱 안에서 봅니다.
- 강의계획서 내용을 채팅으로 묻습니다.
- 학교 탭과 웹 탭을 앱 안에서 함께 씁니다.

제출, 신청, 예약은 학생이 학교 화면에서 직접 합니다. 학생은 앱이 연 학교 로그인 화면에서 로그인합니다.

## 내려받기

[Releases](https://github.com/leetae9yu/KUrowser/releases) 페이지에서 가장 위에 있는 버전을 받습니다. 지금 버전은 모두 시험판입니다.

| 기기 | 파일 |
| --- | --- |
| Windows (Intel, AMD) | KUrowser-버전-x64-setup.exe |
| Windows (ARM) | KUrowser-버전-arm64-setup.exe |
| macOS (Apple Silicon) | KUrowser-버전-arm64.dmg |
| Android | KUrowser-버전-android.apk |

## 설치

### Windows

1. 설치 파일을 실행합니다.
2. "Windows의 PC 보호" 창이 뜨면 [추가 정보]를 누른 뒤 [실행]을 누릅니다.

### macOS

1. dmg를 열고 KUrowser를 응용 프로그램 폴더로 옮깁니다.
2. 처음 열 때 Finder에서 앱을 Control-클릭한 뒤 [열기]를 누릅니다.
3. 키체인 허용 창이 뜨면 맥 암호를 넣고 [항상 허용]을 누릅니다. 이 창은 업데이트한 뒤에도 한 번 뜹니다.

### Android

1. 휴대폰에서 apk 파일을 받습니다.
2. 파일을 열고, 출처를 알 수 없는 앱 설치를 묻는 창이 뜨면 허용합니다.
3. [설치]를 누릅니다.
